# 开发者工作台

浏览器和 Tauri 主窗口共用一套哈希路由。侧栏可以折叠，窄窗口从顶栏打开导航。资源详情在宽窗口停靠于右侧，空间较小时显示为抽屉。底部状态栏显示应用版本和已连接的演示主机数。未知路由回到总览。[路由入口](../../src/App.tsx) · [工作台外壳](../../src/app/AppShell.tsx)

## 页面与操作

| 页面 | 哈希路由 | 可以做什么 |
| --- | --- | --- |
| 总览 | `#/` | 从最近项目、开发环境、Git 动态、GitHub 待办、远程连接和活动记录进入对应资源。「自定义总览」可调整卡片顺序及显隐。主要依赖清单和灵动岛设置入口在页面底部。 |
| 项目 | `#/projects` | 搜索项目，按语言或标签筛选，切换列表与网格。可新增、编辑、移除演示项目，复制路径或固定到首页。详情可跳到关联的环境、仓库和主机。 |
| 开发环境 | `#/environment` | 按运行时、工具链或包管理器查看资源。可筛选安装状态、查看安装说明、模拟检测，并在已有版本间切换默认值。 |
| Git 工作区 | `#/git` | 选择样本仓库及分支，查看文件变更、提交记录、分支和远端。可模拟克隆、修改文件、提交、拉取和推送。提交会更新该分支的记录及领先数量。 |
| GitHub | `#/github` | 切换演示账户，搜索仓库、PR 和 Issue，查看协作活动。仓库详情可进入已有的演示 Git 工作区，或打开模拟克隆入口。 |
| 远程中心 | `#/remote` | 按主机切换 SSH 连接、服务器指标、文件、终端、Docker 资源和部署日志。模拟连接后，可将样本文件加入传输队列，或在终端会话中输入命令查看预设回显。 |
| 工具箱 | `#/toolbox` | 在前端执行 JSON 格式化、UTF-8 Base64 编解码、日期与时间戳双向转换。时间戳支持秒、毫秒、UTC 和本地时区。可复制结果或清空输入。 |
| 设置 | `#/settings` | 「外观」进入 `#/settings/appearance` 选择浅色、深色或跟随系统。「导航自定义」进入 `#/settings/navigation` 管理分组、顺序、显隐和收藏。「灵动岛设置」入口为 `#/settings/island`。 |

侧栏的「最近使用」和「活动记录」分别定位到 `#/?section=recent` 和 `#/?section=activity`。隐藏导航项只影响侧栏，原地址仍可访问。[导航定义](../../src/app/navigation.ts)

## 数据与保存范围

| 数据 | 存放位置与生命周期 |
| --- | --- |
| 项目、环境、Git、GitHub、远程资源和活动记录 | 各模块的 Redux 状态从内置样本初始化，当前窗口的页面共享。比如在项目详情选择「固定到首页」，总览的最近项目会显示同一条记录。刷新页面或重建主窗口后重新加载样本。模拟操作只更新演示记录。 |
| 主题、侧栏和导航分组 | 保存在当前浏览器或 WebView 的 `localStorage`，键名为 `zx-once.workbench.preferences.v1`。 |
| 总览布局、最近使用的工具 | 分别保存到 `localStorage` 的 `zx-once.overview.layout.v1` 和 `zx-once.toolbox.recent.v1`。工具记录只含工具标识。输入和转换结果仅在当前工具视图中保留。 |
| 主窗口会话 | Windows 主窗口关闭回到托盘时，原生进程保留依赖清单展开状态。从灵动岛设置关闭时也保留有效分组与草稿。托盘「打开主界面」可恢复该设置页，从其他业务页面重开则进入总览。退出应用会释放这份内存快照。 |

在总览或业务样本页打开「演示数据」菜单，可切换加载中、无数据或读取失败，GitHub 和远程中心还可切换无权限。项目路径复制和工具箱结果复制使用设备剪贴板。[状态入口](../../src/store.ts) · [演示状态控件](../../src/app/workbenchUi.tsx) · [工具转换](../../src/features/toolbox/conversions.ts) · [窗口快照](../../src-tauri/src/island/manager/main_window.rs)
