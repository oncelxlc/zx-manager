# 灵动岛

Windows 桌面应用在屏幕边缘显示一个置顶的原生窗口。默认停靠在主显示器顶部，以收起状态启动。通过「设置 → 灵动岛设置」或托盘菜单的同名入口打开 `#/settings/island`。浏览器和其他平台可在设置页调整草稿、预览外观和动画。保存配置、读取系统信息和控制原生窗口需要 Windows 桌面应用。

## 岛上内容

| 场景 | 显示与操作 |
| --- | --- |
| 收起 | 显示本地时间。顶部停靠时可显示伙伴，有电池读数时可显示电量和接电状态，有媒体标题时显示波形。极简模式会缩小岛体并省略提醒入口。 |
| 展开或固定 | 主面板显示日期、时间和音乐卡片。Windows 系统媒体会话提供曲名、艺人、封面和进度。上一首、播放/暂停、下一首和跳转进度按播放器支持的能力启用。无曲目时显示「暂无音乐」。有曲目时可点击「词」切换布局，歌词区显示「暂无歌词」。 |
| 微信或 QQ 有系统提醒 | 收起态在对应客户端运行且存在匹配的系统提醒时显示应用入口。单个可激活窗口可直接切换，多实例先展开选择，数量较多时可翻页。收到提醒不会自动切换前台。[Windows 通知与安装权限](../special/windows-notifications.md) |

## 设置与生效时机

「总览」中可以立即显示、隐藏、固定或重启已启用的岛体。启用开关、各分组的参数和「恢复默认设置」先进入草稿。「外观」和「动画效果」分组提供页内预览。点击「保存设置」将草稿应用到桌面岛体。

- **启动管理与位置。** 可设置登录 Windows 时启动、应用启动时显示以及启动时收起。普通安装通过当前用户注册表的 Run 项管理登录启动，MSIX 使用 Windows 启动任务。位置可跟随主显示器或指定屏幕，支持顶部、左侧和右侧停靠。沿边位置用 `-100` 至 `100` 的整数百分比表示，`0` 为居中。指定屏幕断开时优先回退到主屏，其次取首个可用屏幕，配置保留原选择。
- **鼠标与边界。** 可分别开启悬停展开、点击展开、固定和拖动。指针离开未固定的展开面板后，岛体收起，再按设置保持收起、延时缩成边缘条或完全隐藏。悬停边缘条会按唤醒延迟恢复，点击可立即恢复。完全隐藏后可从托盘或设置页重新显示。
- **外观与动画。** 可选刘海或胶囊、主题与配色、透明度、阴影和毛玻璃。岛体大小按 5% 一档在 80% 至 140% 间调整。动画设置控制预设、时长、幅度、减少动态效果和性能档位。
- **通知。** 保存「启用通知」后，已启用的岛体开始发现客户端并检查通知权限。关闭该选项会停止通知监听并清空当前实例和提醒。

普通 Windows 安装将配置写入 `%APPDATA%\com.oncel.zx-once\island.json`。MSIX 使用包身份对应的应用配置目录。写入前会将现有配置备份为 `island.json.bak`。如果文件损坏，可退出应用，保留损坏文件，再将备份复制为 `island.json`。保存时在文件锁内核对 `revision`，如有版本冲突，放弃草稿并载入新值即可重新编辑。开启「记住拖动后的位置」会保存拖动结果，关闭时位置只在本次岛体运行期间生效。[配置定义](../../src-tauri/src/island/config.rs) · [配置读写](../../src-tauri/src/island/config_store.rs)

## 窗口状态与渲染

停用会释放原生窗口和监听，重新启用后进入收起态。固定态在指针离开和前台应用进入全屏时保持显示。开启「全屏应用运行时隐藏」后，普通收起态、展开态和边缘条会在全屏期间暂停显示，退出全屏时恢复之前的状态。关闭工作台主窗口后，原生岛体和托盘继续运行，使用托盘的「退出应用」结束进程。[状态机](../../src-tauri/src/island/state.rs)

设置页通过 Tauri 命令向 Rust 管理线程提交操作，订阅配置、状态、屏幕、位置和运行错误事件。管理线程串行处理命令和超时。独立的 Win32 窗口线程处理鼠标、拖动和绘制，置顶显示时保留前台应用的焦点。鼠标命中与 MSAA 读屏操作共用控件布局。[设置页](../../src/features/island/IslandSettingsPage.tsx) · [原生管理器](../../src-tauri/src/island/manager.rs)

Direct2D 与 DirectWrite 将图形和文字绘制到 DXGI 交换链，DirectComposition 合成展开和收起等过渡。渲染器按状态缓存纹理，窗口线程随轮廓更新可点击区域，让透明部分的点击落到下层窗口。设备丢失时渲染器会尝试重建资源，仍有绘制错误时可在「总览」重启岛屿。[渲染实现](../../src-tauri/src/island/render/mod.rs) · [窗口命中区域](../../src-tauri/src/island/surface/placement.rs) · [性能诊断](../special/island-performance.md)
